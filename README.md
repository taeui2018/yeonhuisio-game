# 연희시오 야탑점 — 오늘의 셰프 도전

매장에서 기다리는 손님이 QR로 바로 플레이하는 1분 웹게임입니다.

- 게임 주소: https://taeui2018.github.io/yeonhuisio-game/
- 매장 QR: https://taeui2018.github.io/yeonhuisio-game/?src=qr
- 네이버 플레이스용: https://taeui2018.github.io/yeonhuisio-game/?src=naver

메뉴·링크·난이도는 `index.html` 맨 위의 `CONFIG`, `MENU`, `IMAGES`만 고치면 됩니다.
(`game.html`은 `index.html`과 같은 파일입니다.)
